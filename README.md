# CRM That Doesn't Suck (working name, provisional)

**EU-sovereign CRM, and actually good to use.**

Two separate problems, don't conflate them:

1. **Sovereignty.** The best-regarded open-source CRMs today — Twenty (Paris-HQ'd) and Odoo (Belgium-HQ'd) — are EU-*headquartered*, but both carry real US venture capital exposure (Odoo: Summit Partners, and a 2026 secondary sale involving AVP/Alkeon; Twenty: Y Combinator, Runa Capital). Same shape of risk that made Jitsi's 8x8 ownership a problem for EU-sovereignty claims — just via capital instead of outright acquisition.
2. **Quality.** Most open-source CRMs are functional but nobody loves using them. "Doesn't suck" is a real design bar here, not a slogan — it needs to turn into a concrete list of what Twenty/Odoo/SuiteCRM/EspoCRM actually get wrong, not just a vibe.

## Status: early, deliberately unfinished

Scaffold and invitation, not a product yet. The premise has to be strong enough that people want to build on it — that's the whole point of starting unfinished rather than polishing solo.

## Governance

Intended to be governed by **Powerworks Foundation** (Ireland-based nonprofit, being set up as of 2026-11-02 — does not yet legally exist). Seeded under the Powerworks-Global GitHub org temporarily until the Foundation has its own org.

## What's actually decided so far

- Not yet decided: fork an existing codebase (Twenty is MIT-licensed, so legally available) vs. build fresh.
- Not yet decided: the concrete "doesn't suck" acceptance criteria — this is the first real thing to nail down before any code gets written.

## Contributing

If you've used Twenty, Odoo, SuiteCRM, or EspoCRM and have a specific, nameable complaint — that's exactly what this needs first. Open an issue with it.
